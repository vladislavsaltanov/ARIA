# ARIA

Профессиональный кроссплатформенный аудиоплеер для звукорежиссёров мероприятий (театр, концерты, конференции): мгновенный отклик, отказоустойчивость «шоу не должно остановиться», дистанционное управление из браузера по локальной сети.

## Language

### Библиотека

**Track**:
Библиотечная запись одного аудиофайла: теги, waveform-кэш, дефолтные настройки (корректирующий gain). Один Track — один файл.
_Avoid_: файл, песня, композиция

**Playlist**:
Управляемый документ из PlaylistEntry. Сам по себе не воспроизводится — порядком воспроизведения управляет Queue.
_Avoid_: сет, сет-лист, вкладка

**PlaylistEntry**:
Использование Track внутри Playlist. Может переопределять дефолты Track (cue-точки, фейды, имя, цвет, gain).
_Avoid_: item, строка плейлиста, трек

**Override**:
Значение на PlaylistEntry, заменяющее дефолт Track. Без override вхождение наследует дефолт.
_Avoid_: кастомизация, исключение

**Faulted**:
Сессионная пометка Track, чьё декодирование не удалось; снимается автопроверкой при следующем обращении. Сама по себе не утверждает, что файл испорчен.
_Avoid_: битый файл, сломанный трек

### Воспроизведение

**Deck**:
Единственный канал основного воспроизведения: «текущий + следующий», кроссфейд выполняется внутри аудио-микшера. Второй деки нет.
_Avoid_: канал A/B, плеер, поток

**Queue**:
Упорядоченный оверлей поверх плейлиста: сначала играется Queue, затем воспроизведение продолжается по Playlist с текущей позиции. Когда оба пусты — стоп.
_Avoid_: очередь задач, буфер

**EndAction**:
Действие Deck при достижении конца воспроизведения — конец файла, CuePoint-out или автостоп по Marker. Варианты: пауза, стоп, перезапуск текущего вхождения, переход к следующему с кроссфейдом. Дефолт задаётся на Track, переопределяется Override'ом.
_Avoid_: режим реплики, автопауза, loop

**Preview**:
Прослушивание неиграющего трека на канале прослушки до вывода в зал.
_Avoid_: PFL (строго — тейп играющего трека до фейдера), cueing

**PANIC**:
Команда высшего приоритета: глушит всё — основной выход и прослушку — фейдом ≤100 мс (настраиваемо вплоть до мгновенного стопа). Восстановление только вручную; автовозобновления нет.
_Avoid_: kill switch, стоп-всё

### Разметка файла

**CuePoint**:
Граница воспроизведения внутри файла: точка входа и/или выхода.
_Avoid_: cue, точка монтирования

**Marker**:
Именованная позиция в файле с привязанным действием при пересечении во время воспроизведения (например, автостоп).
_Avoid_: cue point, флажок

### Шоу и управление

**Pairing**:
Статическая пара «идентификатор + пароль», которой пульт доказывает хосту право подключения. Идентификатор стабилен; пароль можно задать вручную или сбросить на случайный. Сессионный токен — временный артефакт пары, живёт до перезапуска хоста.
_Avoid_: логин, аккаунт, PIN, токен (токен — не пара)

**Show**:
Рабочее состояние оператора: плейлисты, очередь, позиции воспроизведения, настройки. Сохраняется автоматически и восстанавливается после сбоя.
_Avoid_: сессия, проект, workspace

**Session**:
Активация аудио-движка: устройства, шины, частота. С Show не совпадает и не сохраняется.
_Avoid_: show (в смысле рабочее состояние)

**Trigger**:
Внешний сигнал шоу — MIDI-событие, MSC-команда, hotkey, — запускающий привязанную команду плеера.
_Avoid_: cue, макрос

**Script**:
Сценарий — рабочий документ оператора: строки свободного текста с временем от старта Show и Mention'ами треков. Один на Show, часть Show. Исполнение строки ставит упомянутый трек в Queue.
_Avoid_: run sheet, cue sheet, кью-лист, заметки, реплики

**Mention**:
Упоминание в строке Script: ссылка на Track по идентификатору. Хранится идентификатор, отображается имя; повисшее упоминание — серая плашка.
_Avoid_: тег, ссылка
