# BUG-2026-09-16T220000: упоминание сценария играет трек вне проекта

## Problem

Actual: сценарий ссылается на трек, удалённый из проекта, — упоминание всё равно запускает воспроизведение.

Expected: упоминания резолвятся только в треки внутри активного проекта; чужой трек не играет (молча, как dangling), команда отклоняется с причиной.

Repro: трек в сценарии → удалить трек из проекта (трек остаётся в библиотеке) → выполнить упоминание → играет.

Security impact: LOW. Remote `play_track` с чужим TrackId тоже играет — trust boundary пульта: чужой id теперь отклоняется.

## Root Cause Analysis

Путь: клик упоминания → VM guard → `PlayTrack(TrackId)` → контроллер ищет в глобальной карте треков → играет.

Почему играет чужой (проверено чтением кода): VM `IsKnownTrack` проверяет наличие в библиотеке (`_trackSource`), контроллер `OnPlayTrack` — в `_trackMap`. Членство в проекте не проверяет никто. Удаление записи из проекта библиотеку не чистит — сирота остаётся играбельной.

Производители PlayTrack: только упоминания (3 точки VM), remote `play_track`, тесты. Очередь и превью идут другими путями — не задеты.

Risk level: Low. Меняется только комбинация «PlayTrack на трек вне активного проекта», ранее не покрытая.
