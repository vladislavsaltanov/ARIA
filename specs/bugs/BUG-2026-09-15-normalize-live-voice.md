# BUG-2026-09-15-normalize-live-voice: нормализация не слышна без перезапуска трека

## Problem

- Actual: включение нормализации и кнопка «Измерить» не меняют показания LUFS-счётчика в докбаре, пока трек играет. Эффект появляется только после перезапуска трека.
- Expected: замер и тогглы меняют звук и счётчик сразу на играющем треке.
- Reproduce: играть трек, открыть «Звук…», включить нормализацию глобально и на треке, нажать «Измерить» — статус показывает замер и поправку, а LUFS-полоска стоит.

## Root Cause Analysis

- Контроллер применяет аудио-настройки только на старте стрима: голос микшера создаётся с резолвленным аудио один раз.
- Единственный живой путь обновления голоса существует в движке, но контроллер его не вызывает ни из одного хендлера.
- Хендлеры измерения, per-track/entry правок и глобальных настроек обновляют только stored-настройки и шлют дельты состояния. Играющий голос остаётся со старым гейном.
- Смена глобального таргета тоже не пересчитывает живые голоса, хотя движок резолвит офсет именно в момент подачи аудио на голос.
- Risk level: Low — фикс идёт через уже существующий живой путь движка, новых интерфейсов не нужно.

Security impact: NONE — no security exploit path identified.
