# BUG-2026-09-16T200000: импорт папки теряет отчёт и валится на битом файле

## Problem

Actual: выбора папки нет (только файлы); отчёт движка (added/skipped/failed) игнорируется VM — итог строится эвристикой совпадения; исключение декодера на одном файле обрывает весь батч; недоступная подпапка роняет всю папку; список расширений продублирован в трёх местах.

Expected (ТЗ 3.1): выбор/drag&drop папки; рекурсивный поиск поддерживаемых файлов; битые/неподдерживаемые не прерывают остальных; в конце «импортировано N, пропущено M, ошибок K» с именами.

Security impact: LOW. Рекурсивный обход чужих деревьев: symlink-петли и глубокие деревья глушим guards; нового чтения вне выбранного дерева нет.

## Root Cause Analysis

Путь: кнопка/drop → VM-обёртка (прогресс + сверка с плейлистом) → хост (раскрытие папок → последовательный декод → Upsert в библиотеку) → импортёр файла.

Почему не по ТЗ (проверено чтением кода, scout-отчёт в сессии):

1. Папку нечем выбрать: используется только file-picker; folder-picker нигде не вызывается.
2. Отчёт теряется: движок возвращает added/skipped/failed, VM его отбрасывает и пересчитывает совпадения эвристикой (папка → match по префиксу). Имена реально битых файлов в диалоге — сами входы, не файлы внутри.
3. Батч хрупкий: исключение импортёра не ловится в цикле — await прерывается, остаток и Upsert теряются.
4. Раскрытие жадное и ломкое: один вызов на всё дерево материализует список; ошибка доступа на подпапке даёт ноль файлов вместо пропуска подпапки; петель/лимитов нет.
5. Контрибьютор: расширения в трёх местах — рассинхрон неминуем.

Не регрессия. Недореализация + хрупкость.
