# AGENTS.md

Правила работы в репозитории ARIA для агентов и будущих сессий.

## Git — ведём постоянно

- После каждого крупного батча изменений (завершённый модуль/срез с зелёными тестами) — коммит с подробным описанием и push.
- Формат коммита: заголовок ≤ 72 символов, пустая строка, тело — что сделано, зачем, ключевые решения, количество тестов.
- Коммить только проверенное: `dotnet build` без ошибок, `dotnet test` зелёный, 0 предупреждений (`TreatWarningsAsErrors`).
- Один логический батч = один коммит. Не смешивать несвязанные изменения.
- Никаких force-push, никаких `--amend` чужих коммитов, не коммитить bin/obj/временные файлы/секреты.
- Remote: если origin не настроен — коммитить локально и напомнить пользователю настроить remote; после настройки — догнать push'ами.

## Тесты и качество

- Перед каждым коммитом: `dotnet test` на всём солюшене.
- Никаких комментариев в коде (включая XML-doc). Контракты выражаются именами и тестами.
- File-scoped namespaces, records, иммутабельность, коллекции без мутаций в домене.
- Языковые правила домена — CONTEXT.md; архитектурные решения — docs/adr/ (ADR-критерии: трудно обратить, странно без контекста, реальный трейд-офф).

## Запуск агентов (проверено в этой среде)

- Параллельные запуски task-агентов нестабильны: из батча выживает только первый (повторено дважды). Запускать агентов ПОСЛЕДОВАТЕЛЬНО, один за другим.
- Результат каждого агента проверять на диске (файлы созданы?) и прогоном тестов его проекта; пустой отчёт = работа не сделана.
- Агентам давать брифы с: списком файлов на чтение, жёсткими правилами (без комментариев, 0 предупреждений, границы «можно трогать»), точными сигнатурами, списком тестов и командой проверки `dotnet test <проект>`.

## Архитектура (кратко, детали — docs/adr и код)

- Три шва: `ICommandBus` (управление), `IAudioEngine` (аудио), `ILibraryStore`/`ISnapshotStore` (данные). Тесты — только через интерфейсы.
- Инвариант: PlayerState мутирует только на Control-потоке (владелец `ShowController`).
- Позиция воспроизведения — вне версионированного state (`PlaybackMonitor`, latest-value).
- В аудио-callback/Render: ноль аллокаций, ноль локов (проверяется тестом `GC.GetAllocatedBytesForCurrentThread`).

## Отчётность

- Пользователь общается на русском; идентификаторы кода — английские.
- Честно фиксировать: что сделано агентами, что руками; что упало и почему; непроверенные платформы (матрица «проверено» — ADR 0004).
