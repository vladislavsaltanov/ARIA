# Дефолты на Track, переопределения на PlaylistEntry

Настройки воспроизведения разделены на два уровня: библиотечный **Track** хранит дефолты (имя из тегов, корректирующий gain), а **PlaylistEntry** может переопределять cue-точки, фейды, имя, цвет и gain. Причина: один и тот же файл в разных плейлистах (постановках, конференциях) должен вести себя по-разному, при этом типовые исправления («кривой» файл — чиним громкость один раз) остаются в библиотеке.

Отклонённые альтернативы: всё на Track (нет вариативности между плейлистами), всё на PlaylistEntry (дублирование типовых настроек в каждом плейлисте).
