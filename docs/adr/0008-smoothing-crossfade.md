# ADR 0008: сглаживание переключений (AIMP-style)

Дата: 2026-09-13. Статус: принято.

## Контекст

Нужны 4 параметра: кроссфейд вручную (даблклик), кроссфейд по очереди (авто),
скорость запуска (fade-in), скорость затухания (пауза/стоп), плюс вкл/выкл.

## Решение

- Ручное переключение: старый голос гасится за ManualCrossfade
  (SetMix fade to silence, StopWhenDone), новый стартует с fade-in StartFade.
  Перекрытие настоящее: оба голоса живут в MixerBus одновременно.
- Авто-переключение: старый голос уже мёртв к моменту события Completed,
  заглядывания вперёд в движке нет — AutoCrossfade применяется как fade-in
  нового трека. Настоящего перекрытия нет; честный потолок, не мнимый кроссфейд.
- Пауза/стоп: пауза гасится в MixerBus (PauseWhenFaded, деактивация по
  завершении рампы, без аллокаций/локов в Render); стоп уводит голос
  в retired с fade StopWhenDone.
- Хранение: AppSettings (файл, app-уровень как в AIMP) + MixerState
  (сессионное состояние через SetSmoothing). В снапшот шоу не входит:
  это предпочтение приложения, а не данные шоу.

## Альтернативы

- Предстарт следующего трека до конца текущего (настоящий авто-кроссфейд):
  требует lookahead-планировщика в ShowController и владения двумя деками —
  отклонено как шире задачи.
- Отдельные команды на каждый параметр: отклонено, один SetSmoothing
  атомарно несёт пятёрку.
