# ADR 0009: ShowController остаётся одним файлом

Дата: 2026-09-14. Статус: принято.

## Контекст

ShowController вырос до ~1630 строк: диспетчер команд плюс когорты
транспорта, очереди, плейлистов, сценариев, часов и событий движка.
Предлагался сплит на классы когорт
(ShowLoader/TransportCmds/QueueCmds/PlaylistCmds/ScriptCmds/ClockConfig).
Оценка — assess-impact + deepen-architecture + совет (oracle, reviewer),
импакт в specs/IMPACT_LATEST.md.

## Решение

- Extract-class когорт — отклонён. Все когорты делят мутабельное
  состояние (_current, флаги статуса, очередь, карты,_preRolled, retired)
  и общий emit-хвост; вынос требует god-контекста ради нулевого выигрыша
  шва (один адаптер — гипотетический шов). Ослабляет инвариант:
  PlayerState мутирует только здесь, на control-потоке.
- Файл — глубокое диспетчерское ядро (малый шов IShowHandler, большое
  скрытое поведение), deletion test проходит. Размер — от ширины
  (40+ команд), а не от расхождения.
- Partial-классы по когортам — допустимы позже как чистая навигация,
  только по доказанной боли (конфликты мержей, навигация).

## Альтернативы

- Полный сплит сейчас: отклонён — shallow seam, Feature Envy,
  самый большой дифф без выгоды.
- Рефакторинг при появлении второго владельца когорты, повторных
  merge-конфликтов разных когорт или cohort-бага, не ловимого тестами, —
  честные триггеры пересмотра.
