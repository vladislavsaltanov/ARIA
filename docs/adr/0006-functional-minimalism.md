# Дизайн-язык: функциональный минимализм

UI следует принципу функционального минимализма (референс — Nothing): монохромная тёмная основа, никаких декоративных красок и градиентов. Цвет в интерфейсе — только функциональный: метки треков, статусы соединения/воспроизведения, подсветка PANIC. Жёсткое требование: любые элементы управления и показания уверенно читаются при плохом освещении — высокий контраст, крупный цельный шрифт счётчика оставшегося времени, крупные touch-цели. Отклонено: яркие акценты как декор — они не несут информации и слепят оператора в полутьме за пультом.
