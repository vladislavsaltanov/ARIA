# Системный микшер по умолчанию, прямой доступ к устройству — opt-in

По умолчанию вывод идёт через общий путь платформы, системный микшер остаётся жив: WASAPI shared (Windows), CoreAudio HAL (macOS), PulseAudio/PipeWire (Linux). Прямой (эксклюзивный) доступ — опция на конкретное устройство: WASAPI exclusive (Windows), hog mode (macOS — miniaudio его не отдаёт, потребуется небольшое нативное расширение, фаза 4), ALSA `hw`-устройство (Linux — отбирает выход у PipeWire). Причина: целевая машина — рабочий ноутбук звукорежиссёра, где предсказуемость (звук не пропадает из-за занятого устройства, системная громкость и уведомления работают) важнее bit-perfect; про-случаи покрыты opt-in. Режим вывода — свойство **Session**, а не Show.

Отклонено: exclusive по умолчанию — монополия устройства делает смену частоты и переключение источников деликатной операцией ради выигрыша, который для живого звука через конференц-микшер не критичен.
