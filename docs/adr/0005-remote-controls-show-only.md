# Веб-пульт управляет Show, библиотека остаётся desktop-only

Веб-пульт — поверхность управления текущим **Show**: транспорт, очередь, плейлисты, поиск по ним, назначение Preview, PANIC. Импорт файлов, редактирование библиотеки и разметка (CuePoint/Marker) — только в desktop-приложении. Причина: граница контекста резко сужает протокол (нет передачи файлов и конфликтных правок) и упрощает auth-модель; партиция `library` в протокол пульта не входит — пульт получает только данные тех Track, что присутствуют в его Show. Отклонено: пульт с полным функционалом (передача файлов по LAN, конфликтующие правки одного Show с двух устройств).
