# Платформенная матрица «проверено»: win-x64, osx-arm64, linux-x64

Обещание «поведение проверено» даётся только для трёх платформ, под которые существуют физические стенды: Windows x64, macOS Apple Silicon, Linux x64. Остальные RID (osx-x64, linux-arm64, win-arm64) собираются и публикуются, но не заявляются как проверенные. Причина: честная матрица тестов вместо фиктивного «кроссплатформенно»; платформенно-зависимые отличия документируются явно для этих трёх ОС.
