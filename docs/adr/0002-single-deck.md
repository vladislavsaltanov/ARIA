# Single deck, dual-deck вне скоупа

Воспроизведение идёт через единственную **Deck**: «текущий + следующий», кроссфейд выполняется внутри аудио-микшера, а не переключением дек. Dual-deck A/B (DJ-стиль, ручное армирование каналов) сознательно исключён: целевой пользователь — звукорежиссёр театра/конференции; вторая дека усложнила бы state store, протокол и пульт без требования из предметной области. Прослушка следующего трека решается отдельным каналом прослушки на второе устройство, а не второй декой.
