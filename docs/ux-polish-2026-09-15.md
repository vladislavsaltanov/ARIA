## 1. Часы одни, transport разгружен

Было: `ShowClockText` + `TimerSubText` дважды — крупно в `PlaybackHeader`
(36pt + sub) и мелко в `TransportBar` (14pt + 11pt, колонка MinWidth 86).
Transport — 10 колонок на MinWidth 1100, первым под переполнение попадал volume/clock.

Стало: мини-часы удалены из `TransportBar.axaml`, сетка 10 → 9 колонок
(`Auto,Auto,Auto,*,Auto,Auto,Auto,Auto,Auto`), Lock/Settings/PANIC перенумерованы
7→6, 8→7, 9→8. Каноника показаний — крупный циферблат header.
ViewModel не тронут: `TransportViewModel.ShowClockText/TimerSubText` живут дальше,
их биндит header (общий DataContext). Тики `RefreshWallClock` в `TransportBar.axaml.cs`
не тронуты — часы header обновляются тем же таймером.

Файлы: `src/ARIA.App/Views/TransportBar.axaml`.

## 2. Rail: активное выделение плейлиста

## 3. Строка entry: бейдж EndAction + fault-тап по строке

Было: per-entry override виден только в контекстном меню «Действие в конце».
Сканировать плейлист «где не-наследовать» нельзя. Fault-иконка 13×13, тап только
по ней (`OnFaultIconTapped`) — мимо ADR-0006 (крупные touch-цели в полутьме).

Стало:

- `EntryVm`: `HasEndActionOverride`, `EndActionBadge` («Пауза»/«Стоп»/«Повтор»/«Далее»,
  пусто при наследовании), `EndActionTip` («Действие в конце: …»).
- Строка: новая колонка `Auto` под бейдж (`28,*,Auto,58,110,32`), шрифт 10 `BrushDim`,
  тултип из `EndActionTip`, виден только при override. Waveform 118→100 чтобы влезть.
- Fault: иконка 13→16, колонка 20→32, отступы ужаты. Вся строка кликабельна:
  `Tapped="OnFaultRowTapped"` на `Border.plRow` — открывает `ShowFaultDialog`
  только при `IsFaulted`, иначе тап идёт как раньше (селект). Тап по иконке ставит
  `Handled`, двойного диалога нет.

Файлы: `src/ARIA.App/ViewModels/PlaylistsViewModel.cs`,
`src/ARIA.App/Views/PlaylistCenter.axaml`, `src/ARIA.App/Views/PlaylistCenter.axaml.cs`.

Файлы: `src/ARIA.App/Views/ScriptPanel.axaml`, `src/ARIA.App/Views/ScriptPanel.axaml.cs`.

## Как проверять вручную

1. Старт: часы только сверху крупно, в transport их нет; кнопки не налезают на 1100px.
2. Rail: выбранный плейлист светлый semibold.
3. Правый клик по строке → «Действие в конце» → Пауза: в строке бейдж «Пауза».
4. Поиск «xyz»: счётчик «0 из N»; крестик чистит.
5. Кнопки «+ Аудио» / «+ Плейлист» добавляют файлы / открывают `.aria-playlist.json`.
6. Сценарий Ctrl+T: у каждой строки видимый play; клик исполняет в Queue.
7. Fault-строка: клик в любом месте открывает причину (диалог Найти/Убрать/Игнорировать).
