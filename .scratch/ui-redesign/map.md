# Спека нового UI: компактный рабочий интерфейс оператора

Labels: wayfinder:map
Effort: ui-redesign

## Destination

Спека нового десктоп-интерфейса ARIA (`.scratch/ui-redesign/spec.md`): компоновка окна, транспорт-бар, панель сценария, глобальные таймеры и LUFS-метр, громкость, хоткеи, пополнение библиотеки. Все решения закрыты; спека достаточна, чтобы сессии-реализаторы работали без дополнительных проектных решений. Сама реализация — за пределами этой карты.

## Notes

- Домен: ARIA — аудиоплеер для звукорежиссёров мероприятий; язык — CONTEXT.md (Track, Playlist, PlaylistEntry, Deck, Queue, EndAction, Preview, PANIC, CuePoint, Marker, Show, Trigger). Термин «Сценарий» — новый, зафиксировать в CONTEXT.md по ходу тикета про сценарий.
- Дизайн-язык: ADR-0006 (функциональный минимализм, Nothing-референс): монохром, цвет только функциональный, высокий контраст, крупные цели — счётчик оставшегося времени не мельчает.
- Скиллы сессий: domain-modeling (обязательно при правке терминов); HITL-тикеты решаются живым разговором, агент не отвечает за человека.
- Референсы пользователя: Spotify (транспорт-бар, библиотека), AIMP, приложенное изображение (waveform-редактор с крупным play и скоростью).
- Ответы пользователя на старте: дестинация — спека; сценарий — рабочий документ с исполнением (клик по строке ставит трек в Queue); таймер — и время шоу, и время суток + elapsed, настраиваемо; границы — десктоп + задел для Remote (веб не реализуем).
- Правила среды (AGENTS.md): task-агентов запускать ПОСЛЕДОВАТЕЛЬНО; код без комментариев; тесты зелёные. Тикеты этой карты код не пишут (кроме прототипов — оговорено в самих тикетах).
- Локальный трекер: map = этот файл; тикеты = `issues/NN-<slug>.md`; блокировки строкой `Blocked by:`; frontier = открытые, не заблокированные, не claimed, по номеру.

## Decisions so far

<!-- по закрытии тикета: - [название тикета](путь): суть ответа одной строкой -->

- [Аудит аудио-движка: громкость, метринг, LUFS](issues/01-research-audio-engine-volume-meters.md): мастер-громкость уже есть целиком (SetMasterGain → движок, UI просто не читает MixerState); momentary LUFS феасибилен в рендер-пути C# (тап после ApplyMasterGain, биквады + ring 400 мс, ноль аллокаций); не хватает сима публикации метрик, тапа и классов K-weighting; Preview не играется вовсе.
- [Аудит UI-кода и Show-состояния](issues/02-research-ui-state-audit.md): мёртвое — QueueViewModel, NextName, Lock-команды нет (только локальные флаги), двойной путь импорта; waveform-кэш пишется, но не читается никем; сценарий ляжет в Show без миграции (опциональные поля), у Note на PlaylistEntry уже есть семантика; аллокационный тест покрывает только аудио-рендер, не UI.
- [Прецеденты сценария оператора](issues/03-research-operator-script-precedents.md): рекомендован гибрид — свободный текст с mention-ссылками по TrackId (Slack-паттерн «хранится ID, рендерится имя», переименование бесплатно, повисшая ссылка деградирует в плашку) + время строки кнопкой «пометить сейчас» (elapsed, абсолют — проекция); прецеденты: QLab memo cues, ТВ-rundown с soft/hard time.
- [Avalonia-паттерны](issues/04-research-avalonia-patterns.md): волна — custom Control с кэшированной StreamGeometry (WriteableBitmap избыточен); drawer — SplitView Right Overlay/CompactOverlay; иконки — PathIcon + StreamGeometry из Lucide/Feather с конвертацией stroke→fill (риск закрыть прототипом); хоткеи — жесты в ToolTip из HotkeyConfig + help-оверлей по F1.
- [Информационная архитектура: от табов к постоянной компоновке](issues/05-grilling-information-architecture.md): табы упразднены — слева рейка (Библиотека/Плейлисты/Очередь), центр — плейлист, снизу постоянный транспорт-бар, справа выезжает панель Сценария; крупный счётчик над контентом; PANIC в правом краю бара; REMOTE → диалог настроек; LOCK → хоткей + индикатор, лок становится командой Show.
- [Транспорт-бар: состав, громкость, LUFS-метр](issues/06-grilling-transport-bar.md): бар 64px; инфозона «играющий + Далее» (NextName оживает); Play/Pause тумблер + Stop + Next; тонкий прогресс по верхней кромке; справа LUFS (число+полоска, MUTED при PANIC) → громкость (слайдер 0–100%→−80…+12 дБ, дБ в тултипе, mute по иконке) → слот таймеров → замок → настройки → PANIC. Волна — над контентом, не в баре. Отказы: Replay (только Ctrl+R), отдельные Play/Pause, LOCK, REMOTE, StatusText. Движку нужны: сим метрик, тап + K-weighting, Muted-флаг.
- [Сценарий: доменная модель и исполнение](issues/07-grilling-script-domain-model.md): термины Script (Сценарий) и Mention внесены в CONTEXT.md; строка — свободный текст + Mention на Track по TrackId, время — «пометить сейчас» (elapsed времени шоу, абсолют — проекция); один Script на Show, часть Show-state без миграции; умный клик (1 упоминание → Queue, несколько → выбор, 0 → заметка), EndAction по обычным правилам; follow-mode — автоподсветка текущей строки по elapsed; таймкоды сценария и show clock — одна система координат.
- [Таймеры: show clock и время суток](issues/08-grilling-global-timers.md): show clock стартует первым PLAY, паузы/стопы/PANIC не останавливают; оба показания сразу без переключателя — слот бара, две строки (сверху show clock крупнее, снизу время суток + elapsed трека); сброс только вручную (хоткей + меню настроек); elapsed и running-флаг — часть Show-state, восстанавливаются после сбоя.
- [Хоткеи: дефолты и обнаруживаемость](issues/09-grilling-hotkeys.md): 8 жестов (6 текущих + Ctrl+T toggle сценария + Ctrl+Shift+C сброс часов); тултипы «действие — жест» на кнопках + F1-оверлей с полной таблицей; UI-редактор жестов в настройках (запись нажатия, валидация конфликтов), hotkeys.json — формат хранения; единый реестр действий: хоткеи, кнопки и будущие MIDI/MSC-Trigger'ы диспатчат одни команды ICommandBus.
- [Библиотека: добавление треков и поток в плейлист/очередь](issues/10-grilling-library-flows.md): импорт — «+ Import» + drag&drop из Finder (папки рекурсивно, дубликаты skip с отчётом, Faulted с пометкой); строка — имя/длительность/waveform-миниатюра/Faulted, поиск-подстрока; double-click = enqueue, drag в плейлист (позиция) и очередь (конец), контекст-меню; плейлист — drag-порядок и inline-переименование; очередь — колонка справа от плейлиста, Clear в шапке, без автоскрытия. Мета-кнопки ADD TO ACTIVE/ENQUEUE/RENAME/SET NAME/UP/DOWN умирают.
- [Remote-задел: соответствие понятий веб-пульту](issues/14-grilling-remote-concepts.md): пульт = Транспорт + Очередь + Плейлист + Сценарий только-чтение (follow-mode, смарт-клик поверх существующего enqueue_track) + громкость + LUFS + таймеры; desktop-only — редактирование сценария, библиотека, разметка, лок/анлок, настройки, waveform. LOCK — индикатор, шина отвергает команды пульта при локе, PANIC обходит лок. В Show-партицию добавляются Locked-флаг, Script и TrackDigest (имена треков Show для плейлистов и упоминаний, без библиотечной партиции — ADR-0005 цел); LUFS на пульт — вне версионированных партиций, event-кадр по образцу «position» (~10 Гц). Новых команд протокола нет.
- [Прототип главного окна](issues/11-prototype-main-window.md): ассет `.scratch/ui-redesign/prototype/` (Avalonia 12.1.2, вне солюшена); компоновка рейка+центр+очередь+бар+drawer подтверждена реакцией. Поправки: бар **76px** вместо 64 (тикет 06) + **seek кликом по волне**; PANIC красной рамкой, Ctrl+Shift+P; AIMP-нумерация строк и имя-файла-вместо-метаданных в настройки (тикет 10). Нативный DnD Avalonia 12 на macOS сломан (мгновенная отмена/креш) — в прототипе in-app drag, в спеку раздел рисков. Драг-потоки тикета 10 работают (reorder+перенумерация, lib→плейлист/очередь, Clear, индикатор вставки).
- [Прототип панели сценария](issues/12-prototype-script-panel.md): drawer на данных (7/50/новый): текст-клик = правка (время вручную + «пометить сейчас», Enter коммитит + новая строка, «+ строка» везде), фон/таймкод/go/чип = исполнение (умный клик тикета 07), чип подсвечивает трек в библиотеке и плейлисте, drag reorder строк, разделение 8. Построено вручную (агенты недоступны — DNS).
- [Миграция: судьба текущих вьюх и ViewModel](issues/13-grilling-migration-fate.md): VM живут (QueueViewModel возрождается без MoveUp/Down и Locked; RemotePanelViewModel дословно в диалог настроек; Playlists/Library худеют до живых жестов, SET NAME/RENAME умирает со старыми вью); канонический импорт — AppHost.ImportTracksAsync (VM — пикер + отчёт «добавлено N, пропущено M»); порядок: движок+команды Show → бар 76px → рейка/центр → drawer (Script+TrackDigest без миграции) → настройки, каждый шаг зелёный.
- [Сборка спеки: структура и нарезка на усилия](issues/15-grilling-spec-assembly.md): дестинация достигнута — `.scratch/ui-redesign/spec.md` (12 разделов + приложения ссылками, нарезка 5 зелёных срезов, один открытый параметр — порог LUFS §12). Карта закрыта: 15/15.
