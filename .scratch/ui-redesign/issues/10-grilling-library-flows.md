# Библиотека: добавление треков и поток в плейлист/очередь

Type: grilling
Status: open
Blocked by: 05

## Question

«Как добавлять треки» пользователь не понял — значит, путь импорта и заведения в плейлист неочевиден. Решить поток целиком:

- Импорт: кнопка + drag&drop из Finder (Avalonia drag-drop), папка целиком, поведение при дубликатах и Faulted-треках.
- Библиотека: список с поиском/фильтром, сортировка; что показываем в строке (имя, длительность, waveform-миниатюра?, пометка Faulted).
- Заведение в работу: перетаскивание в плейлист, двойной клик = enqueue? контекстное меню? Как «ADD TO ACTIVE» и «ENQUEUE» из текущего UI ложатся на новые жесты.
- Плейлист: редактирование порядка (drag&drop против кнопок UP/DOWN), переименование inline против кнопки SET NAME/RENAME (сегодня кнопка RENAME берёт текст не из своего поля — путаница).
- Очередь: где её видно в новой компоновке (решение схемы окна уже есть), как очищается.

Ответ: карта потоков «файл → библиотека → плейлист → очередь» с конкретными жестами и отказами от мета-кнопок.
