# Прототип главного окна

Type: prototype
Status: resolved
Blocked by: 06, 08, 09, 10

## Question

Компоновка, состав бара, таймеры, хоткеи и потоки библиотеки решены словами — поднять фиделити: дешёвый грубый прототип главного окна (XAML-стаб или статичный макет), на который можно смотреть и говорить «не то».

- Схема окна из тикета компоновки: библиотека/плейлисты, контент, транспорт-бар, место PANIC.
- Бар с реальным составом: громкость, LUFS, таймеры в выбранной конфигурации, тултипы хоткеев.
- Выезжающая панель сценария в закрытом и открытом виде.
- Данные — захардкоженные; цель только обсудить визуальную компоновку и плотность, не поведение.

Ответ: ссылка на ассет прототипа + список правок по итогам реакции пользователя.

## Answer

Решение пользователя (2026-09-11), реакция собрана за 8 раундов question-тул.

**Ассет**: `.scratch/ui-redesign/prototype/` — ARIA.Prototype (Avalonia 12.1.2, вне солюшена, данные захардкожены). Запуск: `dotnet build .scratch/ui-redesign/prototype/ARIA.Prototype.csproj` → `bin/Debug/net10.0/ARIA.Prototype` (в песочнице живёт только путь с `bin/`). Самопроверка геометрий: `ARIA.Prototype --selftest` (26/26).

**Компоновка подтверждена**: рейка (Библиотека/Плейлисты, внизу Очередь/+ Import) + центр с плейлистом (нумерация, поиск, waveform-миниатюры, Faulted) и колонкой очереди + крупные таймеры с волной над контентом + транспорт-бар + SplitView-drawer сценария (Overlay, закрыт по умолчанию) + F1-оверлей жестов.

**Правки по реакции**:

1. Исправлены структурные баги агента: очередь перекрывала центр (`Grid.Column="2"` при двух колонках) — плейлист, шапка и кнопка сценария были скрыты с первого запуска; «?» наезжала на «Сценарий» (колонка 4 при четырёх).
2. Клавиши туннелируются с окна: F1-оверлей и Ctrl+T-drawer работают при любом фокусе (в т.ч. в поиске); клик мимо сбрасывает фокус (focus-sink 0×0, FocusManager).
3. Дизайн сведён с решениями карты: PANIC красной рамкой (ADR-0006, тикеты 05/06) с жестом Ctrl+Shift+P (тикет 09); тултип Play/Pause переключается Space/Esc.
4. Драг-н-дроп тикета 10 реализован и работает: reorder в плейлисте с перенумерацией, библиотека → плейлист (позиция) и → очередь (конец), Clear очереди, живой индикатор вставки (белая линия 4px), подсветка рамки очереди, строка статуса действия.
5. Seek: клик по волне двигает курсор; бар поднят 64 → 76px — **поправка к тикету 06** по реакции пользователя.
6. AIMP-пожелания (тикет 10, в спеку): нумерация строк плейлиста (уже в прототипе); настройка отображения — имя файла вместо метаданных, настраиваемый формат строки.
7. Мелочи: центрирование текстов кнопок и плейсхолдеров поиска, хит-тест строк по всей площади, отступы Faulted-маркеров, разрядка транспортных кнопок, кнопка «Сценарий» с подписью.

**Отклонения и риски для спеки**:

- Нативный DnD Avalonia 12.1.2 на macOS нерабочий: `DoDragDropAsync` из PointerPressed (канонический паттерн ControlCatalog) мгновенно возвращает None; с in-process форматом — креш NSDraggingSession «0 pasteboard items, but 1 drag image». В прототипе — внутриприложенный drag (pointer capture). В спеку — раздел рисков: либо апгрейд/фикс Avalonia, либо свой DnD.
- Нативные экзешники в песочнице убиваются вне `bin/` (AGENTS.md) — прототип запускать только из bin.
- Детали плотности/отступов ждут финального вида в прототипе панели сценария (тикет 12).
