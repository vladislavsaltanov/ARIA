# Транспорт-бар: состав, громкость, LUFS-метр

## Question

Состав постоянного транспорт-бара в новой компоновке (решение по схеме окна уже есть к этому моменту):

- Кнопки: Play/Pause/Stop/Next/Replay — какие остаются как кнопки, какие становятся хоткеями/контекстными действиями; иконки vs текст (ADR-0006: читаемость в полутьме).
- Громкость: ползунок мастера — где, как выглядит, что показывать при отсутствии движковой громкости (результат тикета 01).
- LUFS-метр: моментальный LUFS мастера в баре? Шкала, обновление, поведение при PANIC.
- Информация: играющий + следующий, позиция/полоса прогресса — что входит в бар, что всплывает.
- Waveform (решить явно, из тумана карты): показываем ли волну играющего трека в баре или над контентом у крупного счётчика; данные — peaks из waveforms-кэша (research/04: custom Control + кэшированная StreamGeometry;research/02: кэш пишется, но ни разу не читался). Решение: да/нет/где — и следствие для композиции бара.
- Минимальная высота бара: компактность против touch-целей ADR-0006.

Ответ: макет-описание бара по зонам слева-направо + список отказов («это больше не кнопка, потому что...»).

## Answer

Решение пользователя (2026-09-10), все развилки HITL. Бар 64px, кнопки 44×44 (ADR-0006), иконки PathIcon (Lucide), жесты в тултипах.

**Макет бара слева-направо:**
1. Инфозона (две строки): имя играющего трека жирным; серым «Далее: …» — оживление мёртвого NextName. За прогресс-линией — позиция/длительность моно-шрифтом (PlaybackMonitor).
2. Прогресс: тонкая линия по верхней кромке бара на всю ширину; позиция — из PlaybackMonitor (latest-value, вне версионированного state).
3. Транспорт: Play/Pause — одна кнопка-тумблер 44×44 (иконка по состоянию), Stop и Next — 44×44 рядом.
4. Правая зона: LUFS-метр (моментальный LUFS числом моно-шрифтом + тонкая полоска; за порогом полоска краснеет — функциональный цвет; при PANIC гаснет, надпись MUTED) → громкость (иконка динамика + слайдер ~120px, 0–100% → −80…+12 дБ; тултип показывает точные дБ; клик по иконке — mute, иконка перечёркивается) → слот таймеров (зарезервирован; семантика и конфигурация — тикет 08) → индикатор замка → шестерёнка настроек → PANIC (крупнее прочих, красная рамка).

**Waveform**: да — тонкая полоса волны играющего трека над контентом, рядом с крупным счётчиком; в баре остаётся только линия прогресса. Первое оживление waveform-кэша (peaks уже пишутся, читателей не было).

**Отказы («больше не кнопка, потому что…»)**:
- Replay — не кнопка: редкое, восстановимое действие; живёт на Ctrl+R и в help-оверлее по F1.
- Отдельные Play и Pause — слились в тумблер по состоянию.
- LOCK — не кнопка (тикет 05): хоткей + индикатор.
- REMOTE/pairing — не в баре: диалог настроек по шестерёнке (тикет 05).
- StatusText как текстовая строка — исчез: состояние — иконкой/цветом в баре.
- ДБ на самом слайдере — только в тултипе; лицо слайдера — проценты (выбор пользователя).

**Следствия для движка (из research/01, идут в спеку)**: UI читает MixerState — нужен сим публикации метрик движок→UI; тап в RenderLoop после ApplyMasterGain + классы K-weighting (2 биквада, окно 400 мс, гейт −70) в рендер-пути с нулём аллокаций; Muted-флаг в состоянии громкости (mute помнит предыдущее значение, любое движение слайдера снимает mute); нативный дубль `aria_engine_set_master_gain` удалить — владелец гейна один, C#-путь SetMasterGain.
