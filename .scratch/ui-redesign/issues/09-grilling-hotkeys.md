# Хоткеи: дефолты и обнаруживаемость

Type: grilling
Status: resolved
Resolved: 2026-09-10
Blocked by: 05

## Question

Хоткеи уже есть (Space=play, Escape=pause, Ctrl+Shift+P=panic, Ctrl+N=next, Ctrl+R=replay, Ctrl+L=lock через HotkeyService), но пользователь их не видит: «непонятно, какие хоткеи». Пользователь просит Trigger-привычность (CONTEXT.md: Trigger — внешний сигнал, включая hotkey).

- Дефолтный набор: достаточно ли текущих шести? Чего не хватает (громкость, enqueue выбранного, панель сценария, поиск)? Конфликты с системными жестами macOS.
- Обнаруживаемость: тултипы с жестами на кнопках, help-оверлей по `?`, экран «горячие клавиши» в настройках — что выбираем и как выглядит.
- Кастомизация: HotkeyConfig уже редактируем файлом — оставляем ли файловый конфиг или нужен UI (и когда).
- Связь LOCK: решено тикетом 05 — лок становится командой состояния Show (отвергает управляющие команды на шине), кнопки нет, есть индикатор в баре. Здесь решается только жест и его обнаруживаемость.
- Trigger-словарь: действия хоткеев — те же команды, что слушает MIDI/MSC? Проверить единый реестр действий.

Ответ: дефолтный набор + механизм обнаруживаемости + решение по кастомизации.

## Answer

Решение пользователя (2026-09-10), все развилки HITL:

- **Набор**: текущие шесть + два новых, всего 8 жестов. Дефолты (все перекрываются редактором): Space=play, Esc=pause, Ctrl+Shift+P=panic, Ctrl+N=next, Ctrl+R=replay, Ctrl+L=lock, **Ctrl+T=toggle панели сценария**, **Ctrl+Shift+C=reset show clock** (дефолты двух новых предложены агентом, меняются редактором). Мьют/громкость — только мышь: жестов нет.
- **Обнаруживаемость**: на каждой кнопке бара тултип «Действие — жест» (жесты читаются из HotkeyConfig); **F1** — полупрозрачный help-оверлей со всей таблицей жестов поверх окна, закрывается любой клавишей (паттерн research/04; «?» как KeyGesture не парсится — потому F1).
- **Кастомизация**: **UI-редактор в диалоге настроек** (выбор пользователя, не файл): таблица «действие — жест», запись нажатия, валидация конфликтов и системных жестов macOS; hotkeys.json остаётся форматом хранения (Save оживает). За границей карты: preview конфликтов в реальном времени.
- **Реестр**: единый словарь действий — HotkeyService диспатчит те же команды ICommandBus, что и кнопки; Toggle панели сценария и Reset clock добавляются в тот же реестр — будущие MIDI/MSC-Trigger'ы вызовут их без новых слоёв (Trigger из CONTEXT.md).
- **LOCK** (перечитан после тикета 05): Ctrl+L остаётся, диспатчит новую команду Show — локальные флаги VM умирают.

Следствия для спеки: раздел «Хоткеи» = таблица 8 жестов + механика F1-оверлея + описание редактора в настройках + правило единого реестра команд. Объём настроек (диалог) пополнился: pairing (05) + редактор жестов (09).
