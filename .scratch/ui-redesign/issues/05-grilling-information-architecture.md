# Информационная архитектура: от табов к постоянной компоновке

Type: grilling
Status: resolved
Resolved: 2026-09-10

## Question

Сегодня окно — 4 таба (TRANSPORT/SHOW/LIBRARY/REMOTE): транспорт скрыт за вкладкой, громкости нет, очередь не видна, «как добавить трек» неочевидно. Пользователь: «максимально интуитивно, максимально компактно, меньше мета-кнопок — больше информации», референсы Spotify/AIMP.

Решить компоновку окна целиком:
- Отказываемся ли от табов в пользу постоянной схемы: библиотека/плейлисты слева, контент в центре, транспорт-бар снизу всегда виден, панель сценария выезжает сбоку?
- Что «больше информации» значит для главного экрана шоу: играющий + следующий, позиции, таймеры, метр — что видно всегда, что по требованию?
- Куда уходят: PANIC (размер/позиция — он не должен потеряться), LOCK (и что лок сейчас вообще значит — это вопрос и для команд), REMOTE/pairing (конфигурация → диалог/настройки?), StatusText.
- Большой счётчик оставшегося времени из ADR-0006 — сохраняем ли в новой компактной компоновке и в каком виде.
- Задел для Remote: какие понятия компоновки должны быть названы так, чтобы веб-пульт их повторил.

Блокируется вопросом феасибилити (громкость/метр) только для состава бара — саму схему окна можно решать сразу.

## Answer

Решение пользователя (2026-09-10), все развилки HITL:

- **Схема окна**: табы TRANSPORT/SHOW/LIBRARY/REMOTE упразднены. Костяк «рейка + бар + drawer» (Spotify-референс): слева постоянная рейка ~260px — Библиотека (поиск + список треков), Плейлисты (активный помечен), внизу рейки — Очередь; центр — активный плейлист; снизу — транспорт-бар, видимый всегда; справа поверх контента — панель Сценария (SplitView, Overlay).
- **Счётчик**: крупный счётчик остатка текущего трека над контентом, всегда виден (ADR-0006 сохранён); в баре — компактные позиция/длительность.
- **PANIC**: правый край транспорт-бара, крупнее прочих кнопок, красная рамка (функциональный цвет), всегда виден.
- **REMOTE**: из таба в диалог настроек (шестерёнка в баре): pairing/QR — конфигурация, а не шоу-режим. StatusText исчезает как отдельная строка: состояние — иконкой+цветом в баре.
- **LOCK**: постоянной кнопки нет — хоткей + индикатор-замок в баре. Лок становится командой состояния Show (не локальным флагом VM): при локе управляющие команды отвергаются на шине — Desktop, хоткеи и Remote-пульт получают одинаковое поведение.
- **Задел для Remote**: понятия «Рейка / Транспорт-бар / Панель сценария / Очередь» названы — веб-пульт повторяет бар + Очередь (детали после тикета сценария).

Исследование опиралось на: research/02 (мёртвое: QueueViewModel, NextName, Lock-флаги; RemotePanel = чистый pairing), research/04 (SplitView Overlay, PathIcon-иконки вместо текстовых кнопок).
