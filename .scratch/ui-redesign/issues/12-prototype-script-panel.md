# Прототип панели сценария

Type: prototype
Status: open
Blocked by: 07, 11

## Question

Доменная модель сценария зафиксирована, главное окно отреагировано — сделать грубый прототип панели сценария (открытое состояние), чтобы решить детали взаимодействия:

- Строка сценария в выбранной модели: таймкод, текст, @упоминание — как выглядит подсветка упоминания, что при hover (пользователь: трек подсвечивается при наведении).
- Исполнение: как выглядит кликабельная строка (go-кнопка? вся строка?), текущая строка при «идём по сценарию».
- Редактирование: где курсор, автокомплит упоминаний, как ставится таймкод (руками? кнопка «пометить текущее время шоу»?).
- Пустое состояние и сценарий с 50 строками — плотность и скролл.

Ответ: ссылка на ассет прототипа + список правок по итогам реакции пользователя.
