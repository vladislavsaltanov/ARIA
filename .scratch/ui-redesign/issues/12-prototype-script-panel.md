# Прототип панели сценария

Type: prototype
Status: resolved
Blocked by: 07, 11

## Question

Доменная модель сценария зафиксирована, главное окно отреагировано — сделать грубый прототип панели сценария (открытое состояние), чтобы решить детали взаимодействия:

- Строка сценария в выбранной модели: таймкод, текст, @упоминание — как выглядит подсветка упоминания, что при hover (пользователь: трек подсвечивается при наведении).
- Исполнение: как выглядит кликабельная строка (go-кнопка? вся строка?), текущая строка при «идём по сценарию».
- Редактирование: где курсор, автокомплит упоминаний, как ставится таймкод (руками? кнопка «пометить текущее время шоу»?).
- Пустое состояние и сценарий с 50 строками — плотность и скролл.

Ответ: ссылка на ассет прототипа + список правок по итогам реакции пользователя.

## Answer

Решение пользователя (2026-09-11), реакция за 3 раунда question-тула.

**Ассет**: `.scratch/ui-redesign/prototype/` (тот же ARIA.Prototype, drawer переписан на данные). Построено **вручную**: task-агенты трижды не отработали (два пустых отчёта, затем ENOTFOUND openrouter.ai) — честная фиксация по AGENTS.md.

**Что решено реакцией**:

1. **Клик-зоны строки разделены**: клик по тексту включает редактирование строки (TextBox + «@» + «пометить сейчас»); исполнение — клик по фону/таймкоду, go-кнопка play при наведении, клик по чипу (свой трек напрямую).
2. **Mention ↔ трек**: hover/клик по чипу подсвечивает строку трека в библиотеке И в текущем плейлисте (класс linked); тултип чипа — имя и длительность; повисшее — серая плашка.
3. **Редактирование**: время — ручной ввод (поле «м:сс») + «пометить сейчас» (= elapsed 01:23:45); текст — свободный ввод; Enter коммитит строку и открывает новую пустую; кнопка «+ строка» во всех демо; чип «новый» — чистый сценарий; клик мимо коммитит правку; пустая строка видна тусклым плейсхолдером и кликается в правку; удаление упоминания — клик по чипу в режиме правки.
4. **Порядок строк**: drag reorder внутри панели с живой линией вставки.
5. **Плотность**: разделение строк 3 → 8; 50 строк скроллятся; пустое состояние с кнопкой принято.

**Найденные грабли прототипа**: `FindControl` не находит кодовые TextBox (текст терялся при ререндере) — прямые ссылки на контролы; ресурсы только через `Application.Current`; Popup в Avalonia 12 — свойство `Placement`, не `PlacementMode`, и вне Border-родителя.
