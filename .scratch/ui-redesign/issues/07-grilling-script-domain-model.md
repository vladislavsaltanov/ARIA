# Сценарий: доменная модель и исполнение

Type: grilling
Status: open
Blocked by: 02, 03, 05

## Question

Сценарий — новое доменное понятие ARIA. Решение пользователя на старте: рабочий документ с исполнением — клик по строке ставит упомянутый трек в Queue. Зафиксировать модель и термин:

- Термин в CONTEXT.md: «Сценарий»/Script/RunSheet — выбрать каноническое английское имя для кода и русское для речи.
- Модель строки: таймкод (абсолютный по времени шоу? относительный?), свободный текст, @упоминания — чем ссылка является (Track? PlaylistEntry?), что при переименовании/удалении трека.
- Принадлежность и persist: сценарий часть Show (версионированный state, автосохранение)? Один на Show или на плейлист?
- Исполнение: клик по строке → Queue (существующая семантика Queue поверх плейлиста). Что с EndAction, с уже играющим треком. Нужен ли «идём по сценарию» режим (подсветка текущей строки по show clock).
- Связь с глобальным таймером: таймкоды сценария и show clock — одна система координат?
- Панель: ширина, поведение выезда, хоткей показа, поведение при маленьком окне.

Ответ: термин + модель (запись в CONTEXT.md делается в этом же тикете) + поведение исполнения.
