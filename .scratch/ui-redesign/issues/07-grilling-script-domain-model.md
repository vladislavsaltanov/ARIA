## Question

- Модель строки: таймкод (абсолютный по времени шоу? относительный?), свободный текст, @упоминания — чем ссылка является (Track? PlaylistEntry?), что при переименовании/удалении трека.
- Принадлежность и persist: сценарий часть Show (версионированный state, автосохранение)? Один на Show или на плейлист?

- Связь с глобальным таймером: таймкоды сценария и show clock — одна система координат?
- Панель: ширина, поведение выезда, хоткей показа, поведение при маленьком окне.

## Answer

Решение пользователя (2026-09-10), все развилки HITL. Термины внесены в CONTEXT.md: **Script** (Сценарий) и **Mention** (Упоминание).

- **Термин**: Сценарий в речи, Script в коде (ScriptLine, ScriptPanel). _Avoid_: run sheet, cue sheet, кью-лист, заметки — конфликт с дисциплиной глоссария (Trigger: _Avoid_: cue).
- **Строка**: гибрид по research/03 — свободный текст + Mention'ы внутри; время строки ставится кнопкой «пометить сейчас» = elapsed времени шоу (до старта шоу elapsed = 0, пометка работает всегда); абсолютное время суток — проекция отображения, не поле.
- **Принадлежность**: один Script на Show, часть версионированного Show-state с автосохранением (research/02: ложится в штатный путь Commands → ShowController → StateEvents → SnapshotStore, миграции нет).
- **Исполнение**: умный клик — одно упоминание: ставит трек в Queue; несколько: компактный выбор в строке; ноль: строка только заметка. EndAction — обычные правила Track/Override, повторный клик — снова в конец Queue (семантика Queue не меняется).
- **Mention** ссылается на Track по TrackId (Slack-паттерн): хранится ID, рендерится имя, переименование бесплатно, повисшая ссылка — серая плашка. Override'ы — путь через плейлист, не через сценарий.
- **Follow-mode**: автоподсветка текущей строки — время строки ≤ elapsed < время следующей с временем. Сценарий и show clock — одна система координат; старт/сброс/конфигурация часов — тикет 08.
- **Панель**: toggle-хоткей существует (жест назначит тикет 09); ширина/поведение при малом окне — прототип (тикет 12).
