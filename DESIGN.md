# DESIGN.md — ARIA «Show Console»

Режим: Operate. Пульт живого шоу, не витрина. Знакомость важнее
выразительности: скелет (рейл / центр / очередь / часы / транспорт)
сохранён, перерисован голос: табло, крупные мишени, один сигнальный цвет.

## Tokens

| Key | Value | Use |
|---|---|---|
| BrushBg | #0F0F0F | окно |
| BrushSurface | #161616 | панели, строки |
| BrushSurfaceAlt | #1F1F1F | hover, поиск, попапы |
| BrushSurfaceHi | #2A2A2A | активное, упоминания |
| BrushLine | #2C2C2C | разделители |
| BrushFg | #ECECEC | основной текст |
| BrushDim | #8A8A8A | вторичный текст (5.2:1 на Surface) |
| BrushFaint | #565656 | только декор: иконки, волна. Не текст |
| BrushFaulted | #E5484D | faulted, PANIC |
| BrushSignal | #E5A63B | сейчас в эфире: курсор, прогресс, текущие строки (8.3:1) |
| BrushSignalSoft | #2A2113 | подложка текущих строк (янтарь 7.5:1) |
| BrushOk | #6FCF7B | пульт подключён, измерено |
| MonoFont | Menlo, Consolas | часы, счётчики, значения |

Сигнал один — янтарь. Красный только авария. Зелёный только «в норме».

## Type

Одна семья + моно для чисел. Шаги: 11 моно мета · 12 вторичка ·
13 тело · 17–19 заголовки · 40 часы шоу. Трекинг не ниже −0.04em,
заголовки balanced. Числа всегда моно, значения — с единицами.

## Space

Ритм 4/8/12/16/24. Группы плотно, разделы широко, над заголовком
воздуха больше, чем под ним. Мишени транспорта 44–48px, строки
очереди 40px, строки плейлиста 44px.

## States

Играет: сигнальная подложка + глиф, не только цвет. Текущая строка
сценария: подложка SignalSoft + кромка Signal 2px — осознанное
исключение из запрета на цветные кромки: метка живой строки это
продуктовый сигнал пульта, а не декор. Hover/selected/disabled/empty
у всех списков. Пустые состояния говорят, что делать дальше.

## Surfaces

- PlaybackHeader: табло 40 моно, точка эфира при идущих часах,
  курсор волны сигнальный.
- TransportBar: play 48px с сигналом в игре, прогресс сигнальный,
  PANIC отделён и красный.
- PlaylistCenter: плотность 44px, faulted-иконка, linked-подложка,
  пустое состояние с действием.
- QueueColumn: текущая строка сигнальная, высота 40px.
- RailProjects: выбранный — Fg SemiBold, остальные Dim.
- ScriptPanel: живой строке — подложка и кромка, упоминания —
  пилюли Hi, повисшие — приглушены.
- RemotePanel: токены вместо хардкода, QR-карта белая (скан),
  статус — Ok/Dim.
- SettingsDialog + 8 секций + TrackAudioView: заголовки Fg,
  метки Dim 12, значения моно 11, кнопки action.
