# PRODUCT.md — ARIA

Профессиональный кроссплатформенный аудиоплеер для звукорежиссёров мероприятий:
мгновенный отклик, отказоустойчивость «шоу не должно остановиться»,
дистанционное управление из браузера по локальной сети.

## Users

Звукорежиссёр живого мероприятия (театр, концерт, конференция).
Работает в тёмном зале, в перчатках спешки: один взгляд на экран,
одна крупная мишень под рукой. Ошибка стоит сорванной репликой.

## Jobs

- Собрать порядок воспроизведения (Playlist) и держать поверх него
  оперативный оверлей (Queue): сначала Queue, дальше Playlist с текущей позиции.
- Видеть часы шоу и волну играющего трека, держать позицию и уровень.
- Глушить всё одной кнопкой (PANIC, фейд ≤100 мс) и восстанавливать вручную.
- Прослушивать трек до эфира (Preview), размечать вхождения (CuePoint, Marker).
- Вести сценарий (Script): строки со временем от старта шоу и упоминаниями
  треков; исполнение строки ставит трек в Queue.
- Подключать пульт из браузера по LAN (Pairing: стабильный идентификатор
  + пароль, QR).

## Non-goals

Вторая дека, соцсети, стриминг, свет. Маркетинговых поверхностей нет.

## Platform

Desktop: macOS / Windows / Linux (Avalonia Fluent, тёмная тема) — мобильных
сборок нет, устройство одно: рабочая станция звукорежиссёра. Окно 1440×900,
минимум 1100×700. Тёмный зал — тёмная тема единственная.
Русскоязычный интерфейс, английские идентификаторы кода.

## Constraints

- PlayerState мутирует только на Control-потоке.
- Ноль аллокаций и локов в аудио-callback и Render.
- Тесты только через интерфейсы (ICommandBus, IAudioEngine,
  ILibraryStore/ISnapshotStore).
- 0 предупреждений сборки, полный `dotnet test` зелёный перед коммитом.
- Терминология — CONTEXT.md.

## Accessibility

Контраст текста ≥4.5:1, крупного ≥3:1. Видимый фокус на всех
интерактивных элементах — оператор живёт на hotkey и Tab.
Мишени транспорта ≥44px. Никакого смысла только через цвет:
у состояния всегда есть текст или глиф.
